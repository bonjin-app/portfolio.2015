# 문서 안내

이 디렉터리는 읽는 목적에 따라 문서를 분리합니다. 처음 실행하려는 사람과
구조를 이해하려는 사람이 같은 긴 문서를 읽지 않도록 구성했습니다.

## 처음 사용하는 경우

1. [시작 가이드](GETTING_STARTED.md)에서 설치하고 첫 화면을 확인합니다.
2. 콘텐츠를 수정하려면 [개발 가이드](DEVELOPMENT.md)를 읽습니다.
3. 운영에 반영하려면 [배포 가이드](DEPLOYMENT.md)를 따릅니다.

## 목적별 문서

| 분류 | 문서 | 답하는 질문 |
| --- | --- | --- |
| Tutorial | [시작 가이드](GETTING_STARTED.md) | 로컬에서 어떻게 실행하나요? |
| How-to | [개발 가이드](DEVELOPMENT.md) | 콘텐츠와 정적 작업물을 어떻게 수정하나요? |
| How-to | [배포 가이드](DEPLOYMENT.md) | 어떻게 검증하고 운영에 배포하나요? |
| Reference | [기술 참조](REFERENCE.md) | 명령, 경로와 파일 역할은 무엇인가요? |
| Explanation | [아키텍처](ARCHITECTURE.md) | 왜 React와 레거시 HTML을 함께 사용하나요? |
| Quality | [품질 관리](QA.md) | 무엇을 자동·수동으로 검사하나요? |

## 유지 원칙

- 명령이나 경로가 바뀌면 [기술 참조](REFERENCE.md)를 먼저 갱신합니다.
- 작업 절차가 바뀌면 관련 How-to 문서와 README 링크를 함께 갱신합니다.
- 설계 이유가 바뀌면 [아키텍처](ARCHITECTURE.md)에 대안과 비용을 기록합니다.
- 운영 결함을 수정하면 [품질 관리](QA.md)에 회귀 검사 항목을 추가합니다.
- 모든 새 문서는 저장소 루트 README에서 두 번 이내의 클릭으로 접근할 수 있어야
  합니다.
