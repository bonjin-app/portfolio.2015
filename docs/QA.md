# QA & Bug Fix Notes

## 수정한 결함

| 영역 | 기존 문제 | 수정 |
| --- | --- | --- |
| 모바일 작품 링크 | AutoCamping이 폐기된 HTTP 도메인을 새 창으로 열어 실패 | 보존된 `/legacy/html/Web_renew_m/index.html`로 연결 |
| 사이드 메뉴 | About 구간만 `on` 클래스를 사용해 활성 표시가 누락 | 모든 구간을 `active`로 통일 |
| 스크롤 경계 | Home 범위가 About 시작점과 겹쳐 About 표시가 늦게 변경 | 섹션 시작점을 기준으로 단순화 |
| 모바일 메뉴 | 연속 스크롤 때 닫기 애니메이션이 큐에 누적 | 기존 큐를 중단한 뒤 최신 애니메이션 실행 |
| 메인 슬라이드 | 이미지 수를 3으로 가정하고 시작 순서가 뒤틀림 | 실제 항목 수를 기준으로 다음 이미지 계산 |
| 로그인 갤러리 | 첫 이미지가 두 번째 이미지와 중복 | `login1.jpg`부터 1–7 순서로 복구 |
| 진명홈바스 | 외부 HTTP 주소에 의존 | 저장소에 보존된 정적 사이트로 연결 |
| 이미지 로더 | 존재하지 않는 `loader.gif`가 운영에서 404 발생 | 사용되지 않는 배경 요청 제거 |
| HTML/CSS 문법 | viewport 중복·오타, CSS 안의 HTML 주석, h6 크기 오타 | 유효한 메타 태그와 CSS 문법으로 정리 |

## 배포 전 검사

```bash
npm run lint
npm run build
node --check public/legacy/js/script.js
git diff --check
```

브라우저 회귀 검사는 다음 해상도에서 수행합니다.

- 1280×720: 변경 전·후 초기 화면 픽셀 비교
- 390×844: 원본 모바일 레이아웃과 메뉴 확인
- AutoCamping: 모바일 정적 페이지가 새 탭에서 열리는지 확인
- 사이드 메뉴: About, Works, Contact 활성 상태 확인
- JSP 로그인 갤러리: 1 of 7로 열리고 `login1.jpg`부터 시작하는지 확인

초기 화면의 유일한 시간 의존 요소는 아래 화살표의 jQuery opacity
애니메이션입니다. 모바일 캡처 해시가 다를 때는 이 요소의 애니메이션 프레임
차이인지 확인합니다.
